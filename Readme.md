# Password Manager

Gerenciador de senhas em React com validação da senha em tempo real.

> Projeto desenvolvido durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/) (2023).

## Funcionalidades

- Cadastro de serviço, login, senha e URL
- Validação da senha em tempo real: 8 a 16 caracteres, letras e números e caractere especial
- Lista de senhas cadastradas, com opção de remover
- Mostrar ou esconder senhas

## Stack

React 18 · TypeScript · Vite · Vitest · React Testing Library

## Como rodar

```bash
npm install
npm run dev
```

Testes:

```bash
npm test
```
